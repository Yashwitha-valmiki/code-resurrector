# Code Resurrector

Paste a public GitHub repo URL for an abandoned project. Open-weight Gemma 4
reads the README and dependency files and writes a revival report: what the
project did, why it likely died, what is probably broken, and a 5-step plan
to bring it back.

## Run it

pip install -r requirements.txt
python -m streamlit run app.py

Get a free API key at aistudio.google.com and paste it in the sidebar.
Never commit your key.

Built for the Hacktoberfest Open-Source AI Challenge, Week 4.
